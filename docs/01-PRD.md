# Go2Shell 产品需求文档（PRD）

> 版本：v1.0 草案 · 日期：2026-11-21 · 负责人：bingghost
> 状态：待评审。文中标注「可改」的地方是默认决定，可以随时调整。

> 命名：本项目叫 Go2Shell（Bundle ID `com.bingghost.Go2Shell`）。文中的「旧 Go2Shell」指 ZipZapMac 的 Go2Shell 2.5（`com.zipzapmac.Go2Shell`），两者同名但不是同一个 App。

## 1. 背景

- 我现在用的是 Go2Shell 2.5（`com.zipzapmac.Go2Shell`），它是一个**纯 x86_64** 的 App，在 Apple Silicon 上只能靠 Rosetta 2 运行。Apple 已经在逐步收缩 Rosetta，再升级几次系统，它很可能就打不开了。
- 旧 Go2Shell 的作者已经多年没有更新过它。
- 开源替代品（比如 solarhell/go2shell）可以参考，但存在以下问题：
  - 不支持自定义命令
  - 路径转义有隐患
  - 健壮性一般

  另外我想对代码有完全的掌控。
- **目标**：自己开发一个原生 Apple Silicon 的替代品，长期自己维护。

## 2. 产品定位

一个**放在 Finder 工具栏上的按钮**：点一下，就在当前 Finder 目录打开你常用的终端，然后自己退出。除了第一次设置，平时完全感觉不到它的存在。

## 3. 目标用户与场景

| 角色 | 说明 |
| --- | --- |
| 主要用户 | 我自己：开发者，主力终端是 iTerm2，习惯旧 Go2Shell 的使用方式 |
| 次要用户 | 其他开发者，用 Terminal.app、Ghostty、WezTerm、Kitty、Alacritty 或 Warp |

主要场景：

1. **S1 一键打开**：在 Finder 里浏览到某个项目目录，点工具栏上的 Go2Shell，iTerm2 立刻开一个新窗口，`cd` 到这个目录，并执行 `clear; pwd`。
2. **S2 首次设置**：第一次启动时，自动沿用旧 Go2Shell 的配置（终端、命令、窗口模式），然后引导我把 App 拖到 Finder 工具栏上。
3. **S3 修改设置**：按住 ⌥ 点工具栏按钮，或者直接从「应用程序」里打开 Go2Shell，会显示设置窗口。
4. **S4 异常提示**：Finder 没有可用的窗口、目录不是真实路径、自动化权限被拒、终端没装时，给出清楚的提示和解决办法，不会没有任何反应。

## 4. 功能范围

### 4.1 v1.0 必须有（P0）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 工具栏一键打开 | Finder 在最前面时启动本 App，就在 Finder 最前窗口所在的目录打开终端，完成后退出 |
| F2 | 目录解析 | 取最前面 Finder 窗口的目录；没有窗口时用桌面；窗口指向「最近使用」、AirDrop 这类虚拟位置时给出提示 |
| F3 | 支持 iTerm2 | 打开新窗口，执行命令模板 |
| F4 | 支持 Terminal.app | 打开新窗口，执行命令模板 |
| F5 | 命令模板 | 默认是 `cd %PATH%; clear; pwd`。`%PATH%` 会被替换成**经过安全引用**的路径 |
| F6 | 设置窗口 | 可以选择终端（只列出已经安装的）、编辑命令模板（带实时预览）、选择新窗口或新标签 |
| F7 | 打开设置的入口 | 从「应用程序」或 Dock 直接打开、按住 ⌥ 点工具栏按钮、加 `--settings` 参数 |
| F8 | 迁移旧配置 | 第一次运行时读取 `com.zipzapmac.Go2Shell` 的终端、命令和窗口模式 |
| F9 | 权限引导 | 自动化权限被拒时弹窗说明，并提供按钮直接跳转到「系统设置 › 隐私与安全性 › 自动化」 |
| F10 | 工具栏安装说明 | 设置窗口里有图文说明「按住 ⌘ 把图标拖到工具栏」，并提供「在 Finder 中显示本 App」按钮 |
| F11 | 中英文界面 | 根据系统语言自动切换中文或英文 |

### 4.2 v1.x 应该有（P1）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F12 | 新标签模式 | iTerm2 用它的原生 API 开新标签；Terminal.app 通过模拟 ⌘T 实现（需要辅助功能权限，标为「实验性」） |
| F13 | 更多终端 | Ghostty、WezTerm、Kitty、Alacritty、Warp：至少支持在指定目录打开，能执行命令的就支持命令 |
| F14 | 一键装到工具栏 | 自动修改 Finder 的工具栏配置并重启 Finder。操作前先备份，也提供卸载 |
| F15 | 选中项优先 | 选项：如果选中的是文件夹，就在这个文件夹里打开 |

### 4.3 暂不做（P2 / Out of Scope）

- Finder 右键菜单（Finder Sync 扩展）、服务菜单、全局快捷键
- 自动更新（Sparkle）、Mac App Store 上架、公证（没有 Developer ID 证书）
- macOS 14 以下的系统、Intel 机器上的专门测试（只保证能编译出 Universal 版本）

## 5. 交互流程

```
用户点击工具栏图标
        │
        ▼
 Go2Shell 启动 ──按住 ⌥ / 带 --settings / 最前台不是 Finder──▶ 显示设置窗口
        │（Finder 在最前台）
        ▼
 向 Finder 查询最前窗口的目录
   ├─ 拿到真实目录 ───────────────▶ 按设置打开终端并执行命令 ──▶ 退出（≤ 2s）
   ├─ 没有窗口 ──────────────────▶ 使用 ~/Desktop ──▶ 同上
   ├─ 虚拟位置（最近使用等）──────▶ 弹窗「该位置不是文件夹」──▶ 退出
   └─ 权限被拒（-1743）───────────▶ 弹窗 + [打开系统设置] ──▶ 退出
```

- **设置窗口打开时又点了工具栏按钮**：直接执行打开动作，设置窗口不关。
- **配置的终端被卸载了**：退回 Terminal.app，并在设置窗口里提示一次。

## 6. 非功能需求

| 编号 | 需求 | 指标 |
| --- | --- | --- |
| N1 | 原生支持 Apple Silicon | 产物是 arm64（可选 Universal），不依赖 Rosetta |
| N2 | 速度 | 终端已经在运行时，从点击到出现终端窗口 ≤ 1s；本进程 ≤ 2s 退出 |
| N3 | 安全 | 路径和命令拼接不能导致注入。任何目录名（空格、引号、`$`、反引号、换行、emoji、中文）都能正确 `cd` 进去 |
| N4 | 健壮 | 任何错误路径都不能崩溃，最多弹窗提示 |
| N5 | 隐私 | 不联网、不收集数据，只和 Finder 以及选中的终端通信 |
| N6 | 系统版本 | macOS 14 及以上 |
| N7 | 可维护 | 核心逻辑和 UI、系统调用分开，核心逻辑有单元测试 |
| N8 | 签名稳定 | 使用固定的签名身份，重新编译后不需要重新授权自动化权限 |

## 7. 成功标准

1. 删掉旧 Go2Shell 以后，新的 Go2Shell 可以完全替代它日常使用，覆盖 S1–S4。
2. 测试清单（见技术文档 §9）全部通过。
3. 从干净的 checkout 开始，`make install` 一条命令就能装好。
